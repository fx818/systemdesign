# L08 — Forget Me Not  (users milestone: 1,000,000; source: reference/ch1.txt p.20-23 (Stateless web tier))

## Story + lesson content
Incident: after adding server 3, users get randomly logged out. Lesson: move state (session data) out of web tier into persistent store (RDB/NoSQL); stateful server remembers client data between requests; Fig 1-12 user A's session on server 1 -> request to server 2 fails auth; sticky sessions possible but overhead, adding/removing servers hard, failures hard; stateless: any server, state fetched from shared data store; simpler, robust, scalable; shared store could be RDB/Memcached/Redis/NoSQL (NoSQL chosen, easy to scale); autoscaling = add/remove servers automatically by load.

## Lab
Lab: sticky sessions toggle, session-store toggle, servers knob, autoscale toggle, kill server -> see who gets logged out.

## Mini-games
MiniGame 'Who's Logged In?': users A/B/C with session tokens; requests bounce between servers; player decides whether each request succeeds (stateful round) vs moving sessions to the shared store (stateless round).

## Mission
Mission: survive a traffic wave (autoscaling adds/removes servers) and a server kill with zero logouts; palette includes session-store/nosql. Badge 'Stateless'.
