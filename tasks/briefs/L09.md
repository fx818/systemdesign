# L09 — Going Global  (users milestone: 2,000,000; source: reference/ch1.txt p.23-25 (Data centers))

## Story + lesson content
Incident: PixelPost goes international; also a storm takes out US-West for an hour. Lesson: two data centers; geoDNS (geo-routed) to closest DC, x% US-East / (100-x)% US-West; geoDNS resolves domain to IP based on user location; outage -> 100% to healthy DC (Fig 1-16); challenges: traffic redirection (GeoDNS), data synchronization (replicate across DCs; Netflix async multi-DC replication), test & deployment at different locations, automated deployment tools for consistency. Teaser: decouple components -> message queue.

## Lab
Lab: split slider, region map, region-down button, data-replication toggle (without it failover users see missing data).

## Mini-games
MiniGame 'GeoDNS Router': users pop up on a world map, player assigns them to nearest DC; then a DC goes dark and they must re-route everyone fast.

## Mission
Mission: survive full US-West outage at t=40 with uptime >= 99.5% and no data loss (needs cross-DC replication). Badge 'Globetrotter'.
