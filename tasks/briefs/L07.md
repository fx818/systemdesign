# L07 — Closer to Home  (users milestone: 500,000; source: reference/ch1.txt p.17-20 (CDN))

## Story + lesson content
Incident: users in Europe/Asia wait 6s for images. Lesson: CDN = geographically dispersed servers for static content (images, video, CSS, JS); dynamic content caching out of scope; closest CDN server delivers (SF vs LA vs Europe example); 6-step workflow (User A requests image.png via CDN domain e.g. mysite.cloudfront.net / akamai; miss -> fetch from origin (web server or S3); origin returns with TTL header; CDN caches & returns; User B gets it from cache until TTL expires); considerations: cost (don't cache rarely-used assets), expiry (not too long/short), fallback (clients detect CDN outage and go to origin), invalidation (vendor API or versioning image.png?v=2). Fig 1-11: static from CDN, DB load lightened by cache.

## Lab
Lab: world map with users in cities, toggle CDN on/off, edge locations; TTL slider; CDN outage button with/without fallback; version bump button.

## Mini-games
MiniGame 'Order the CDN flow' (drag the 6 steps into order, animated replay) and 'CDN or Not?' (assets: logo, user avatar, 4K launch video viewed once, CSS bundle, API JSON, rarely-used 2015 PDF) with cost meter.

## Mission
Mission: hit global load-time target within budget; CDN outage at t=50 must not break the site (fallback toggle). Badge 'Edge Lord'.
