# L10 — Take a Number  (users milestone: 3,000,000; source: reference/ch1.txt p.25-26 (Message queue))

## Story + lesson content
Incident: Maya launches photo filters (crop, sharpen, blur); uploads now hang for 20s and web servers choke. Lesson: message queue = durable, in-memory, async communication buffer; producers/publishers publish messages; consumers/subscribers connect and act; decoupling: producer can post when consumer is down, consumer reads when producer is down; photo processing example: web servers publish jobs, workers process async; scale producer and consumer independently; big queue -> add workers, empty queue -> fewer workers.

## Lab
Lab: jobs/sec slider, workers knob, kill consumer / kill producer to show decoupling, queue length graph.

## Mini-games
MiniGame 'Worker Shift Manager': timed 60s; upload bursts arrive; player adds/removes workers (each costs credits/sec) to keep the queue under the red line without wasting money; score = SLA met minus cost.

## Mission
Mission: filter launch with bursty jobs; keep web p95 low (requires queue + workers) and queue < threshold. Badge 'Queue Master'.
