# L04 — Traffic Cop  (users milestone: 50,000; source: reference/ch1.txt p.9-11 (Load balancer))

## Story + lesson content
Incident: PixelPost featured on TV, servers drowning. Lesson: LB evenly distributes traffic over a load-balanced set; users hit LB public IP; web servers now unreachable directly; private IPs between servers (reachable only within network); failover — server 1 offline -> all traffic to server 2 + add a new healthy server; rapid growth -> just add servers to the pool, LB starts sending to them. Ends: 'web tier looks good, what about the data tier? one DB = no failover'.

## Lab
Lab: knobs servers 1-6 and rps; chaos kill buttons; watch traffic reroute; public vs private IP labels toggle.

## Mini-games
MiniGame 'Traffic Cop': requests fall in lanes; player taps to route each to the least-loaded healthy server (round-robin feel); servers randomly die; score on dropped requests.

## Mission
Mission: hold 99.9% uptime through a launch surge with a server crash at t=40s; palette: lb, web. Badge 'Load Balanced'.
