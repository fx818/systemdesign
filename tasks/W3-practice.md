# W3-practice — Interview Mode, Sandbox, Daily Puzzle, Survival, Hidden achievements (Codex)
Owns: app/src/practice/** (new), app/src/screens/practice/** (new), and minimal additive edits to app/src/App.tsx
(routes + nav), app/src/game/** (achievements + practice stats, additive, keep existing API & tests),
app/src/screens/HomeScreen.tsx (a "Practice" section with 4 cards; and a chapter selector — see below).

1. CHAPTER SUPPORT in the shell (needed because Chapters 2 & 3 are being added in parallel as app/src/content/ch2, ch3):
   - Use `chapters`/`getChapter` from @/content/chapters and `levelsInChapter`, `chapterOf` from @/content/registry.
   - Home: chapter tabs/cards (title, subtitle, colour, progress, "coming soon" for unavailable); level path shows the
     selected chapter's levels. Chapter N+1's first level unlocks when chapter N's last (or boss) level has >= 1 star.
     Update app/src/game/unlocks.ts accordingly (per-chapter: number 1 open if chapter 1 or previous chapter complete;
     boss rule per chapter) WITH tests; Chapter 1 behaviour must remain identical (existing tests pass).
   - The Chapter-1-specific architecture map stays for chapter 1; other chapters just show their path.
   - Profile/Videos/Review handle multiple chapters.
2. INTERVIEW MODE `/interview` (unlocked after C3L04 >= 1 star OR chapter 1 boss done): pick a prompt from a bank of
   8 (design PixelPost for 10M users, URL shortener-lite, chat app at 1M DAU, news feed, photo upload pipeline,
   notification fan-out, leaderboard, video streaming metadata). Timed 45-min session in the 4 Chapter-3 phases:
   (1) Clarify: choose clarifying questions from a list (good/bad/neutral), reveal requirements;
   (2) Estimate: numeric inputs (DAU->QPS->peak->storage) graded with tolerance against the prompt's hidden numbers;
   (3) Design: build on the real ArchCanvas/SimRunner from @/sim in mission mode with a generated SimConfig from the
       prompt (traffic, events like a server crash) — must pass SLOs;
   (4) Deep dive & wrap-up: pick the bottleneck, answer 3 follow-ups (mcq), pick wrap-up talking points.
   Rubric scoring per phase -> overall grade (Strong Hire / Hire / Lean Hire / No Hire) with explanations, XP.
   PLUS a STRUCTURAL rubric checker `gradeArchitecture(graph, rubric)` (requires e.g. lb before >1 web, replica or
   redundancy for db, cache for read-heavy, cdn for media, queue for async, no SPOF) — reusable, tested.
   Optional AI interviewer: if `localStorage.anthropicKey` is set (settings field on Profile), Ravi asks a follow-up
   generated by the Anthropic Messages API (fetch https://api.anthropic.com/v1/messages, model 'claude-sonnet-4-5',
   header 'anthropic-dangerous-direct-browser-access': 'true') based on the player's graph JSON; fall back to the
   scripted follow-ups when no key. Never hardcode keys.
3. SANDBOX `/sandbox`: SimRunner lab mode with every component, every knob, adjustable traffic and all chaos buttons,
   unlimited budget, plus "Export": PNG of the canvas (serialize SVG -> canvas -> png download), Mermaid text
   (flowchart LR from the graph) copy-to-clipboard, and JSON download/import.
4. DAILY PUZZLE `/puzzle`: deterministic by date (seeded): generate a flawed architecture (SPOFs, missing cache,
   sticky sessions, single DC...) from a set of templates; the player has N moves and a budget to fix it so a scripted
   chaos timeline passes. Streak + share text ("SD Quest #123 ✅ in 4 moves").
5. SURVIVAL `/survival`: build within budget, then endless escalating waves (traffic doubles, random-but-seeded
   failures); score = seconds survived; personal best saved.
6. HIDDEN ACHIEVEMENTS in the game store (additive): Chaos Monkey (kill 5+ nodes in one lab), Zero Downtime (boss mission
   at 100% uptime), Penny Pincher (any mission <= 60% budget), Combo King (x2 combo in a quiz), Night Owl (play after
   midnight), Flawless (3 stars on 5 levels), Puzzle streak 7, Survivor (180 s survival). Show "???" until earned on
   Profile; toast on unlock. Wire the triggers from SimRunner/QuizRunner callbacks via screens (don't rewrite sim/quiz).
